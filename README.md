# To-do-list
Python CLI To-Do List App  A simple command-line based To-Do List application built using Python. This project was developed as a beginner-level practice project to strengthen core programming fundamentals through a real-world use case.
The application allows users to:

Add tasks

View tasks

Mark tasks as completed

Delete tasks

View the updated task list

Exit the program safely


This project focuses on applying foundational Python concepts such as:

Loops

Conditional statements

Lists

User input handling

List indexing

enumerate()

Basic program flow control


Although the project is simple, it helped in understanding how multiple programming concepts work together to build a functional application.

Features

Interactive menu-driven interface

Task management using Python lists

Completion status marking

Dynamic task updates

Beginner-friendly code structure


Purpose of This Project

This project was developed by a beginner who is currently learning Python and practicing problem-solving through small real-world projects. The goal was not to create a perfect production-level application, but to improve logical thinking, understand program structure, and gain hands-on coding experience.

Technologies Used

Python 3
